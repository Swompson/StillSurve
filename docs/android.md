# Android

Проект поддерживает альбомную ориентацию, GLES3 Compatibility на Android и сенсорное управление. На ПК нажмите M (Ь в русской раскладке) во время игры для включения или выключения мобильного интерфейса. F8 не используйте: это команда остановки игры в редакторе Godot. WASD, Shift, мышь и F продолжают работать; мобильные кнопки и стики можно проверять левой кнопкой мыши. Одновременные касания нескольких стиков требуют сенсорного экрана. Аргумент `--touch-controls` по-прежнему включает интерфейс сразу при запуске.

- Левая нижняя зона: движение стиком с постоянной скоростью после мёртвой зоны. В режиме бега через стик выход за тонкое кольцо включает бег. В кнопочном режиме бег включается удержанием отдельной кнопки.
- Правая нижняя зона: направление взгляда плавающим стиком.
- СВЕТ: переключить фонарь.
- ПАУЗА: открыть меню; продолжение и перезапуск доступны кнопками меню.
- При захвате сталкером: нажимать по центру экрана для проверки реакции.

Пауза → Настройки → Управление: выбор способа бега и масштаба HUD (100–180%). Кнопка «Размер и положение кнопок» открывает редактор: перетащите элемент и измените его размер ползунком (65–180%). «Сохранить» записывает раскладку, «Отмена» возвращает предыдущее размещение, «Сброс» восстанавливает стандартное размещение до сохранения. Положение хранится относительно размеров экрана, элементы остаются внутри экрана. Предпочтения сохраняются в `user://mobile_controls.cfg` и восстанавливаются после перезапуска.

Профиль Android сохраняет APK в `builds/StillSurve-Android.apk`, поддерживает ARM64. Android-разработка находится в ветке `codex/android`; ПК-релиз остаётся в `main`. Приложение называется StillSurve, название публикации — StillSurve 0.0.2 preAlpha android. Для сборки нужны Android export templates той же версии Godot, Android SDK и настроенный JDK согласно документации: https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html

На текущей машине установлены Platform-Tools 37.0.1, Command-line Tools 22.0, Build-Tools 35.0.1 и Android Platform 35 в `.godot/android-sdk`. Архив Command-line Tools проверен по SHA-256 Google. Используется JDK 17 из `C:/Program Files/Eclipse Adoptium/jdk-17.0.19.10-hotspot`. Шаблоны Android 4.7.2 находятся в `editor_data/export_templates` установленного Godot в Steam. Пути SDK и JDK настроены в этом редакторе.

Скрипт `tools/build_android.ps1` собирает отладочный APK с локальным ключом `.godot/android-debug.keystore` и выставляет рабочие пути SDK/JDK в настройках Steam-версии Godot перед экспортом. SDK, ключ и журналы остаются в игнорируемой папке `.godot`; APK — в `builds`. Запускать экспорт только после явного запроса пользователя согласно AGENTS.md.

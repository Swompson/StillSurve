# Обход ящиков и скример сталкера

Оригинал `stalker_screamer.mp3` сохранён без изменений в
`assets/audio/user_originals/`; SHA-256 совпадает с предоставленным файлом.
Сохранённый узел `Stalker/Screamer` воспроизводит его при начале захвата,
через Effects и общие отражения и реверберацию Master. Старые записи смеха
остались для реакции на свет; общий скример смерти не изменён.

Крупный граф лабиринта не описывал обходы между складскими коробками.
Теперь заблокированные участки маршрута на складе уточняются общей локальной
сеткой с шагом 24 и проверкой движения круга радиусом 29. Сетка создаётся
при первом необходимом обходе и используется повторно. Исходная геометрия
склада и столкновения сохранены. Охотники обновляют маршрут при перемещении
цели внутри той же клетки; ближние повороты не пропускаются заранее.
Сталкер использует тот же обход, сохраняя отдельные правила скрытых засад.

Godot 4.7.2: `warehouse_chase_regression` проверяет два реальных укрытия,
проходимость всех участков для тела, маршруты обоих типов врагов и физическое
преследование охотником до дистанции атаки. Также прошли `warehouse_regression`,
`stalker_audio_regression`, `stalker_reachability_regression`,
`stalker_concealed_route_regression`, `coordinated_hunters_regression`,
`gameplay_smoke`. В аудиотесте состояние фонаря дополнено полностью поднятой
рукой, чтобы проверять реальное освещение цели.

# StillSurve 0.0.2 preAlpha android

Отдельная Android-ветка `codex/android`; опубликованная ПК-версия остаётся в `main`. Название игры — **StillSurve**.

- Сенсорное движение и взгляд, фонарь, пауза и касание при захвате сталкером.
- Постоянная скорость ходьбы; бег отдельной кнопкой или при выходе стика за кольцо.
- Настройка положения и размеров элементов с сохранением, отменой и сбросом. Масштаб HUD 100–180%.
- Разделённые зоны патрулей двух охотников с приоритетом редко посещаемых коридоров; совместная реакция на шум сохранена.
- Удалены карта нормалей пола и неиспользуемые инструменты её генерации.
- Compatibility / OpenGL ES и внутренний кадр 720p, текстура теней RHalf, восстановление лимита FPS по событиям Android.
- Релизный движок без отладочного флага. ARM64, Android 7.0+, версия пакета `0.0.2-preAlpha-android` (4).

Mobile / Vulkan не включён для Redmi Note 10S: устройство сообщает Vulkan 1.1, ниже заявленного требования Vulkan 1.2 текущего движка. Подтверждённого численного сравнения FPS пока нет: диагностическое приложение оказалось в фоне. Снижение числа пикселей и исправление фонового лимита проверены отдельно; прирост FPS на устройстве требуется измерить в активной игре.

Проверки: android_frame_budget_regression, frame_limit_regression, mobile_layout_settings_regression, patrol_mobile_regression, pause_settings_regression, gameplay_smoke, mounted_fixture_strategies_regression. Подпись APK v2/v3 проверена.
